# Payment-System-Trends-in-India
This dashboard analyzes payment system trends in India across different payment channels and categories. It examines transaction volume, transaction value and year-wise growth to understand how payment methods have evolved over time. 
The time period considered for analysis is 2020-2025. 

The source URL is https://ckandev.indiadataportal.com/dataset/reserve-bank-of-india/resource/1f9367ac-01b0-4c82-83a1-4069d4340667
